# Inspección de Flota Liviana SDE – V4

Versión ajustada para GitHub Pages.

Cambios de esta versión:
- mejora del procesamiento de huella digital para recortar mejor la zona útil y limpiar el fondo;
- paleta visual más profesional en tonos verdes y amarillos;
- se mantienen las funciones de exportación, anexos y guardado local.

Publicación:
1. Descomprime el ZIP.
2. Sube el archivo `index.html` al repositorio de GitHub Pages.
3. Reemplaza el anterior si ya tienes publicada la versión V3.
